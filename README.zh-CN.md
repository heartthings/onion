# 洋葱

一个知识点走进来，一张地图走出去。

下一层看什么，由你决定。标题和概括铺在卡片上。深度解读留在侧栏，卡片上只标一枚「已解读」。

## 它适合干什么

- 一个概念卡住了，先拆开，再决定往哪钻
- 划线、收藏、笔记都留在这张图上
- 今天没记住的，明天还会回来找你

## 跑起来

```bash
npm install
npm run dev
```

浏览器打开 [http://localhost:5188](http://localhost:5188)。

没填模型 Key 也能点。那是演示模式，节点和讲解是占位的，交互是真的。填上 Key 之后，请求从你的浏览器直接打到模型厂商，不经过我们的服务器。

## 怎么学

1. 首页丢进一个具体的概念。范围越小，图越好用。若这句话能指多个真实对象（例如同名人物、同名电影），会先让你选所指；根卡片上还能「换成…」另开一张图。
2. 模型一次最多准备 12 条相关信息，按「能不能看清边界」排序，而不是拆成定义、要素、例子。你在设置里决定先看见几条，剩下的收在「还有 N 个」里。能看见的节点会把整段概括写在卡片上。
3. 点卡片只是打开它。想继续拆，点卡片外侧的加号或「散开」。
4. 深度解读只写在侧栏里。做过解读的节点，卡片上会标「已解读」。在侧栏里选中句子，松开后点「划线」。星标是收藏。左侧「划线 / 收藏」列表悬停可删。
5. 讲解末尾的「继续追问」点一下，会在这个节点旁边长出新节点，并继续散开；解读后还可以继续多轮追问。
6. 每个节点侧边可以标 **懂了 / 模糊 / 不会**。懂了会从「今天要复习」里拿掉（仍收藏的除外）；模糊排到明天；不会立刻到期。模糊和不会的那一支，连线会变成琥珀色或玫红色。
7. 「就地出几道选择题」。答错会自动标成还要再看，并排进今天的复习。
8. 「和另一个对比」之后再点一个节点，并排看相同点和不同点。
9. 按 `N` 或点「我写」自己写一个节点。你写的是蓝色，标着「我写的」，并会默认打开深度解读。

侧栏有 **今天要复习**。划线和收藏会变成卡片，按简化的遗忘曲线排期：忘了就 10 分钟后再见，模糊就明天，记住了就按间隔往后推。

顶栏「导出」可以拿走三样东西：整张地图、划线和笔记的 Markdown、Anki 能导入的文本。

更细的行为说明见 [`docs/product.md`](docs/product.md)。Agent 改功能时以 `docs/` 与 `src/` 为准，不要照抄 `docs/archive/`。

## 快捷键

| 键 | 做什么 |
| --- | --- |
| 方向键 | 在图上移动 |
| Enter | 散开，或打开下一批 |
| N | 自己写一个节点 |
| F | 收藏 |
| R | 今天要复习 |
| Esc | 关掉当前这一层 |
| ? | 快捷键说明 |

在输入框里打字时，这些键不会抢你的字。

## 模型

侧栏左下角进「模型设置」。DeepSeek、通义千问、Kimi、智谱、豆包、OpenAI、OpenRouter、Ollama，以及任何 OpenAI 兼容接口。

Key、地图、划线、复习卡都在浏览器的 IndexedDB 里，库名 `onion`。换电脑不会跟着走，清站点数据会没掉，这是故意的。
