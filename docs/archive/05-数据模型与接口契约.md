```ts
  | 'specific_question'  // 跳到指定步序号
```

## 2. Dexie Schema

```ts
// src/db/schema.ts
import Dexie, { Table } from 'dexie';
import type {
  OnionNode, OnionTree, OnionEdge, ReviewRecord,
  QuizSession, GapItem, ProviderConfig, AppSettings,
  CacheEntry, ChatMessage, GuidedSession,
} from '../domain/types';

export class OnionDB extends Dexie {
  nodes!: Table<OnionNode, string>;
  trees!: Table<OnionTree, string>;
  edges!: Table<OnionEdge, string>;
  reviews!: Table<ReviewRecord, string>;
  quizzes!: Table<QuizSession, string>;
  gaps!: Table<GapItem, string>;
  providers!: Table<ProviderConfig, string>;
  settings!: Table<{ key: string; value: unknown }, string>;
  cache!: Table<CacheEntry, string>;
  chats!: Table<ChatMessage, string>;
  guided!: Table<GuidedSession, string>;

  constructor() {
    super('onion');
    this.version(1).stores({
      // 节点：树+父节点+层 索引
      nodes: 'id, treeId, parentId, [treeId+layer], score, mastery, needsExpand, updatedAt',
      trees: 'id, name, updatedAt',
      edges: 'id, fromId, toId, [fromId+toId], type',
      reviews: 'id, nodeId, dueAt',
      quizzes: 'id, nodeId, createdAt',
      gaps: 'id, nodeId, treeId, resolved, severity',
      providers: 'id, providerId, enabled',
      settings: 'key',
      cache: 'key, expiresAt',
      chats: 'id, nodeId, createdAt',
      guided: 'id, treeId, status, startedAt',
    });
  }
}
export const db = new OnionDB();
```

### 2.1 索引设计说明

| 查询场景 | 用到的索引 |
|---|---|
| 渲染某棵树 | `nodes.where('treeId').equals(id)` |
| 取某节点的子节点 | `nodes.where('parentId').equals(id)` |
| 取某层的所有节点 | `nodes.where('[treeId+layer]')` |
| 待补全清单 | `nodes.where('needsExpand').equals(1)` （需存 0/1 而非 boolean） |
| 今日复习队列 | `reviews.where('dueAt').below(Date.now())` |
| 薄弱节点 | `nodes.where('score').below(40)` |
| 缓存查找 | `cache.where('key').equals(hash)` |
| 进行中的探索会话 | `guided.where('status').equals('active')` |
| 某棵树的探索会话 | `guided.where('treeId').equals(id)` |

> ⚠️ **Dexie 不支持 boolean 索引**。`needsExpand` 在存储层用 `0 | 1`，读取时转回 boolean。
> 实现方式：写库前 `needsExpand: n.needsExpand ? 1 : 0`，类型层用 `as unknown as number` 转换，或在 `schema.ts` 里定义 `type StoredNode = Omit<OnionNode,'needsExpand'> & { needsExpand: 0|1 }`。

### 2.2 存储位置与加密

| 表 | 加密 | 说明 |
|---|---|---|
| `providers.apiKey` | ✅ | 仅当 `rememberKey=true` 时写入 `apiKeyEnc`；`apiKey` 字段运行时存在内存 |
| `providers.apiKeyEnc` | ✅ | AES-GCM 密文，格式 `base64(salt):base64(iv):base64(ciphertext)` |
| 其他所有表 | ❌ | 明文存储于用户本机 IndexedDB |
| `cache` | ❌ | TTL 到期自动清理 |

## 7. 事件约定（跨模块）

| 事件 | 触发方 | 监听方 | 行为 |
|---|---|---|---|
| `node:expanded` | ExpandEngine | Canvas | 播放剥开动画，插入新节点 |

| `node:masteryChanged` | DetailPanel / QuizPanel | Canvas / TreeList | 更新状态点颜色与角标 |
| `node:needsExpand` | QuizPanel / SRS / GapDetection | Canvas | 显示橙色角标 |

> 实现建议：用 Zustand 的 subscribe 或一个轻量 EventBus（`src/lib/bus.ts`），**不要用 window 全局事件**。

## 8. 导入 / 导出格式

### 8.1 全量备份 JSON

```jsonc
{
  "version": 1,
  "exportedAt": 1730000000000,
  "trees": [ /* OnionTree[] */ ],
  "nodes": [ /* OnionNode[] */ ],
  "edges": [ /* OnionEdge[] */ ],
  "reviews": [ /* ReviewRecord[] */ ],
  "quizzes": [ /* QuizSession[] */ ],
  "guided": [ /* GuidedSession[] */ ],
  "settings": { /* AppSettings，不含任何 Key */ }
}
```

**导入规则**：
- `version` 不匹配 → 拒绝导入并提示
- 已有同 id 数据 → 覆盖（先删后插），保证幂等
- **绝不导入 `apiKey` / `apiKeyEnc`**（导出时直接剔除）
- 导入后需 `rebuildIndexes()` 重建 `treeId → nodeIds` 冗余字段

### 8.2 Markdown 导出格式

```markdown

### 1. 注意力机制
> 一句话本质：……

#### 构成
- Query / Key / Value 投影
```

## 10. 契约变更规则

| 变更类型 | 要求 |
|---|---|
| 新增字段 | 可选字段（`?`），带默认值，旧数据自动兼容 |
| 改字段名 | 必须写 Dexie migration（`this.version(2).stores(...).upgrade(...)`） |
| 改语义（如层定义） | 需同时更新 `layers.ts`、Prompt 模板、本文档，并考虑已有树的兼容性 |
| 删除字段 | 先标记废弃，两个版本后再删 |

**Dexie migration 示例**：
```ts
this.version(2).stores({
  nodes: 'id, treeId, parentId, [treeId+layer], score, mastery, needsExpand, updatedAt, tags',
}).upgrade(tx => {
  return tx.table('nodes').toCollection().modify(n => {
    n.tags = n.tags ?? [];
  });
});
```
