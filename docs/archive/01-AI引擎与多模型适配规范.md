# AI 引擎与多模型适配规范

> 供 Code Agent 直接施工 ｜ 所有端点与协议差异已于 2026-10 核对官方文档
> 版本 v1.1 ｜ 新增 §7 引导串 Prompt 契约（来自 Rabbithole 逆向分析）

---

## 1. 设计原则

1. **一套接口，十家厂商**——业务层永远只调用 `provider.chat()`，不感知厂商差异。
2. **协议归两类**——绝大多数国产厂商与 OpenAI 完全同构，只需换 `baseUrl` + `model`；只有 Anthropic 需要独立适配器。这是降低代码量与出错率的关键判断。
3. **浏览器直连**——不建后端。用户自己的 Key 直连厂商 API，服务端不落任何数据。
4. **降级可用**——任一厂商失败，不影响其他厂商可用；设置页永远能打开。
5. **结构化优先**——展开树的场景必须拿到可解析的 JSON，绝不能靠正则从散文里抠。

## 2. Provider 统一接口

```ts
// src/engine/providers/types.ts

export type ProviderId =
  | 'openai' | 'anthropic' | 'qwen' | 'zhipu' | 'deepseek'
  | 'kimi' | 'doubao' | 'openrouter' | 'ollama' | 'custom';

export interface ChatMessage {
  role: 'system' | 'user' | 'assistant';
  content: string;
}

export interface ChatRequest {
  messages: ChatMessage[];
  model: string;
  temperature?: number;      // 默认 0.6
  maxTokens?: number;        // 默认 2048
  topP?: number;             // 默认 0.95
  stream?: boolean;          // 默认 true
  /** 要求 JSON 输出。部分厂商原生支持 response_format，部分靠 prompt 约束 */
  json?: boolean;
  /** 停止词 */
  stop?: string[];
  /** 思考模式（DeepSeek-R1 / GLM thinking / Qwen thinking），部分厂商支持 */
  thinking?: boolean;
  signal?: AbortSignal;
}

export interface ChatUsage {
  promptTokens: number;
  completionTokens: number;
  totalTokens: number;
}

export interface ChatChunk {
  /** 增量文本 */
  delta?: string;
  /** 思考过程增量（若开启 thinking） */
  reasoning?: string;
  usage?: ChatUsage;
  done: boolean;
}

export interface ChatResult {
  content: string;
  reasoning?: string;
  usage: ChatUsage;
  model: string;
  /** 厂商原始响应，排障用 */
  raw?: unknown;
}

export interface ProviderModel {
  id: string;
  label: string;
  /** 是否推荐给用户作为默认 */
  recommended?: boolean;
  contextWindow?: number;
  /** 是否支持流式 */
  supportsStream?: boolean;
  /** 是否支持 thinking */
  supportsThinking?: boolean;
}

export interface LLMProvider {
  readonly id: ProviderId;
  readonly label: string;
  /** 该厂商的默认端点，用户可覆盖 */
  readonly defaultBaseUrl: string;
  readonly defaultModels: ProviderModel[];
  /** 该厂商是否需要额外请求头（如 Anthropic 的浏览器直连头） */
  readonly extraHeaders?: Record<string, string>;
  /** 浏览器直连是否可用（CORS） */
  readonly corsCompatible: boolean;

  chat(req: ChatRequest, apiKey: string, baseUrl?: string): Promise<ChatResult>;
  chatStream(req: ChatRequest, apiKey: string, baseUrl?: string): AsyncIterable<ChatChunk>;
  /** 轻量连通性测试 */
  testConnection(apiKey: string, baseUrl?: string): Promise<{ ok: boolean; latencyMs: number; message: string }>;
}
```

### 3.1 智谱的额外端点（重要）

智谱同时提供 **Anthropic Messages 兼容端点**，若用户希望在智谱上使用 Claude 风格的调用：

| 调用方式 | BaseUrl |
|---|---|
| OpenAI Chat Completions（标准） | `https://open.bigmodel.cn/api/paas/v4` |
| OpenAI Chat Completions（套餐端点） | `https://open.bigmodel.cn/api/coding/paas/v4` |
| Anthropic Messages | `https://open.bigmodel.cn/api/anthropic` |

**实现建议**：智谱走 OpenAI 兼容适配器即可；额外在设置页提供一个「兼容协议」下拉（`auto` / `openai` / `anthropic`），默认 `auto` → 走 openai。

### 3.2 通义千问的思考模式

`qwen3.5-plus` / `qwen3.5-flash` / `qwen3.8-max` 等**默认开启思考模式**，会产生额外的 thinking token（按输出 token 计费）：

```jsonc
// 请求体附加
{ "enable_thinking": false }   // 关闭（展开子节点场景不需要思考，省钱省时间）
{ "enable_thinking": true }    // 开启（出题/对比等需要推理的场景）
```

**默认策略**：展开子节点 `enable_thinking: false`；出题/对比 `enable_thinking: true`。此项必须实现，否则用户会意外多付 token。

## 4. 适配器实现

### 4.1 OpenAI 兼容基类（覆盖 8 家）

```ts
// src/engine/providers/base.ts
export class OpenAICompatibleProvider implements LLMProvider {
  constructor(
    public readonly id: ProviderId,
    public readonly label: string,
    public readonly defaultBaseUrl: string,
    public readonly defaultModels: ProviderModel[],
    public readonly extraHeaders: Record<string, string> = {},
    public readonly corsCompatible = true,
  ) {}

  private url(baseUrl?: string) {
    const b = (baseUrl || this.defaultBaseUrl).replace(/\/+$/, '');
    return `${b}/chat/completions`;
  }

  private buildBody(req: ChatRequest): Record<string, unknown> {
    const body: Record<string, unknown> = {
      model: req.model,
      messages: req.messages,
      temperature: req.temperature ?? 0.6,
      max_tokens: req.maxTokens ?? 2048,
      top_p: req.topP ?? 0.95,
      stream: req.stream ?? false,
    };
    if (req.stop) body.stop = req.stop;
    if (req.json) {
      body.response_format = { type: 'json_object' };
    }
    // 厂商私有参数
    if (this.id === 'qwen' && req.thinking !== undefined) {
      body.enable_thinking = req.thinking;
    }
    if (this.id === 'zhipu' && req.thinking) {
      body.thinking = { type: 'enabled' };
    }
    if (this.id === 'deepseek' && req.model.includes('reasoner')) {
      // deepseek-reasoner 不接受 temperature
      delete body.temperature;
      delete body.top_p;
    }
    return body;
  }

  async chat(req, apiKey, baseUrl) {
    const res = await fetch(this.url(baseUrl), {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${apiKey}`,
        ...this.extraHeaders,
      },
      body: JSON.stringify(this.buildBody({ ...req, stream: false })),
      signal: req.signal,
    });
    if (!res.ok) throw new ProviderError(await parseError(res), res.status, this.id);
    const data = await res.json();
    const choice = data.choices?.[0];
    const content = choice?.message?.content ?? '';
    const reasoning = choice?.message?.reasoning_content ?? undefined;
    return {
      content, reasoning,
      usage: normalizeUsage(data.usage),
      model: data.model ?? req.model,
      raw: data,
    };
  }

  async *chatStream(req, apiKey, baseUrl): AsyncIterable<ChatChunk> {
    const res = await fetch(this.url(baseUrl), {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${apiKey}`,
        ...this.extraHeaders,
      },
      body: JSON.stringify(this.buildBody({ ...req, stream: true })),
      signal: req.signal,
    });
    if (!res.ok) throw new ProviderError(await parseError(res), res.status, this.id);
    if (!res.body) throw new ProviderError('响应无 body', 0, this.id);

    const reader = res.body.getReader();
    const decoder = new TextDecoder();
    let buffer = '';
    let usage: ChatUsage | undefined;

    while (true) {
      const { value, done } = await reader.read();
      if (done) break;
      buffer += decoder.decode(value, { stream: true });

      // SSE: 以空行分隔事件块
      let sep: number;
      while ((sep = buffer.indexOf('\n\n')) !== -1) {
        const rawEvent = buffer.slice(0, sep);
        buffer = buffer.slice(sep + 2);
        for (const line of rawEvent.split('\n')) {
          if (!line.startsWith('data:')) continue;
          const payload = line.slice(5).trim();
          if (payload === '[DONE]') continue;
          try {
            const json = JSON.parse(payload);
            const delta = json.choices?.[0]?.delta;
            if (json.usage) usage = normalizeUsage(json.usage);
            const reasoning = delta?.reasoning_content;
            const content = delta?.content ?? '';
            if (content || reasoning) {
              yield { delta: content || undefined, reasoning: reasoning || undefined, done: false };
            }
          } catch { /* 忽略不完整的 JSON 块 */ }
        }
      }
    }
    yield { done: true, usage };
  }

  async testConnection(apiKey, baseUrl) {
    const t0 = performance.now();
    try {
      await this.chat({
        messages: [{ role: 'user', content: 'ping' }],
        model: this.defaultModels[0].id,
        maxTokens: 8,
        stream: false,
      }, apiKey, baseUrl);
      return { ok: true, latencyMs: Math.round(performance.now() - t0), message: '连接正常' };
    } catch (e) {
      return { ok: false, latencyMs: Math.round(performance.now() - t0), message: errorMessage(e) };
    }
  }
}
```

### 4.2 Anthropic 适配器（独立实现）

Anthropic 与 OpenAI 有 5 处关键差异，必须单独实现：

| 差异点 | OpenAI | Anthropic |
|---|---|---|
| 端点 | `/chat/completions` | `/messages` |
| 鉴权头 | `Authorization: Bearer <key>` | `x-api-key: <key>` |
| 版本头 | 无 | `anthropic-version: 2023-06-01` |
| system 消息 | 在 `messages` 数组内 | **独立的顶层 `system` 字段** |
| 响应取文本 | `choices[0].message.content` | `content[]` 数组，需拼接 `type==='text'` 的块 |
| 流式事件 | `data: {choices[0].delta.content}` | `event: content_block_delta` + `data: {delta:{text}}` |
| 思考内容 | `reasoning_content` | `thinking` 块 / `delta.thinking` |
| max_tokens | 可选 | **必填** |

```ts
// src/engine/providers/anthropic.ts
export class AnthropicProvider implements LLMProvider {
  readonly id = 'anthropic' as const;
  readonly label = 'Anthropic Claude';
  readonly defaultBaseUrl = 'https://api.anthropic.com/v1';
  readonly defaultModels: ProviderModel[] = [
    { id: 'claude-sonnet-4-5',  label: 'Claude Sonnet 4.5（均衡，推荐）', recommended: true },
    { id: 'claude-opus-4-1',    label: 'Claude Opus 4.1（最强）' },
    { id: 'claude-haiku-4-5',  label: 'Claude Haiku 4.5（最快最省）' },
  ];
  readonly corsCompatible = true;
  /** 官方提供的浏览器直连许可头 */
  readonly extraHeaders = { 'anthropic-dangerous-direct-browser-access': 'true' };

  private url(baseUrl?: string) {
    return `${(baseUrl || this.defaultBaseUrl).replace(/\/+$/, '')}/messages`;
  }

  private buildBody(req: ChatRequest) {
    const system = req.messages.filter(m => m.role === 'system').map(m => m.content).join('\n\n');
    const messages = req.messages
      .filter(m => m.role !== 'system')
      .map(m => ({ role: m.role, content: m.content }));

    const body: Record<string, unknown> = {
      model: req.model,
      max_tokens: req.maxTokens ?? 2048,   // Anthropic 必填
      messages,
      stream: req.stream ?? false,
    };
    if (system) body.system = system;
    if (req.temperature !== undefined) body.temperature = req.temperature;
    if (req.topP !== undefined) body.top_p = req.topP;
    if (req.stop) body.stop_sequences = Array.isArray(req.stop) ? req.stop : [req.stop];
    if (req.thinking) {
      body.thinking = { type: 'enabled', budget_tokens: 2048 };
    }
    // Anthropic 无 response_format，JSON 靠 prompt 约束
    return body;
  }

  async chat(req, apiKey, baseUrl) {
    const res = await fetch(this.url(baseUrl), {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'x-api-key': apiKey,
        'anthropic-version': '2023-06-01',
        ...this.extraHeaders,
      },
      body: JSON.stringify(this.buildBody({ ...req, stream: false })),
      signal: req.signal,
    });
    if (!res.ok) throw new ProviderError(await parseError(res), res.status, this.id);
    const data = await res.json();
    const content = (data.content ?? [])
      .filter((b: any) => b.type === 'text')
      .map((b: any) => b.text)
      .join('');
    const reasoning = (data.content ?? [])
      .filter((b: any) => b.type === 'thinking')
      .map((b: any) => b.thinking)
      .join('');
    return {
      content,
      reasoning: reasoning || undefined,
      usage: {
        promptTokens: data.usage?.input_tokens ?? 0,
        completionTokens: data.usage?.output_tokens ?? 0,
        totalTokens: (data.usage?.input_tokens ?? 0) + (data.usage?.output_tokens ?? 0),
      },
      model: data.model ?? req.model,
      raw: data,
    };
  }

  async *chatStream(req, apiKey, baseUrl): AsyncIterable<ChatChunk> {
    const res = await fetch(this.url(baseUrl), {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'x-api-key': apiKey,
        'anthropic-version': '2023-06-01',
        ...this.extraHeaders,
      },
      body: JSON.stringify(this.buildBody({ ...req, stream: true })),
      signal: req.signal,
    });
    if (!res.ok) throw new ProviderError(await parseError(res), res.status, this.id);
    if (!res.body) throw new ProviderError('响应无 body', 0, this.id);

    const reader = res.body.getReader();
    const decoder = new TextDecoder();
    let buffer = '';
    let usage: ChatUsage | undefined;

    while (true) {
      const { value, done } = await reader.read();
      if (done) break;
      buffer += decoder.decode(value, { stream: true });

      let sep: number;
      while ((sep = buffer.indexOf('\n\n')) !== -1) {
        const rawEvent = buffer.slice(0, sep);
        buffer = buffer.slice(sep + 2);
        let eventName = 'message';
        let dataLine = '';
        for (const line of rawEvent.split('\n')) {
          if (line.startsWith('event:')) eventName = line.slice(6).trim();
          else if (line.startsWith('data:')) dataLine += line.slice(5).trim();
        }
        if (!dataLine) continue;
        let json: any;
        try { json = JSON.parse(dataLine); } catch { continue; }

        switch (eventName) {
          case 'content_block_delta': {
            const d = json.delta ?? {};
            const text = d.text ?? '';
            const think = d.thinking ?? '';
            if (text || think) {
              yield { delta: text || undefined, reasoning: think || undefined, done: false };
            }
            break;
          }
          case 'message_delta': {
            if (json.usage) {
              usage = {
                promptTokens: json.usage.input_tokens ?? usage?.promptTokens ?? 0,
                completionTokens: json.usage.output_tokens ?? usage?.completionTokens ?? 0,
                totalTokens: (json.usage.input_tokens ?? 0) + (json.usage.output_tokens ?? 0),
              };
            }
            break;
          }
          case 'message_start': {
            if (json.message?.usage) {
              usage = {
                promptTokens: json.message.usage.input_tokens ?? 0,
                completionTokens: json.message.usage.output_tokens ?? 0,
                totalTokens: (json.message.usage.input_tokens ?? 0) + (json.message.usage.output_tokens ?? 0),
              };
            }
            break;
          }
          case 'message_stop': {
            yield { done: true, usage };
            return;
          }
        }
      }
    }
    yield { done: true, usage };
  }

  async testConnection(apiKey, baseUrl) {
    const t0 = performance.now();
    try {
      await this.chat({
        messages: [{ role: 'user', content: 'ping' }],
        model: this.defaultModels[0].id,
        maxTokens: 8,
        stream: false,
      }, apiKey, baseUrl);
      return { ok: true, latencyMs: Math.round(performance.now() - t0), message: '连接正常' };
    } catch (e) {
      return { ok: false, latencyMs: Math.round(performance.now() - t0), message: errorMessage(e) };
    }
  }
}
```

async function parseError(res: Response): Promise<string> {
  try {
    const data = await res.json();
    // OpenAI: { error: { message } }  Anthropic: { error: { message } }
    // 智谱: { error: { message } }    DashScope: { message } 或 { code, message }
    const msg = data?.error?.message ?? data?.message ?? data?.msg ?? JSON.stringify(data);

  } catch {
    return `${res.status} ${res.statusText}`;
  }

### 5.1 重试策略

| 情况 | 动作 |
|---|---|
| 网络错误 / 5xx | 指数退避重试，最多 2 次（1s、3s） |
| 429 限流 | 退避重试（5s、15s），并 toast 提示"触发限流，可切换模型" |
| 401 / 403 | **不重试**，直接提示"API Key 无效或无权限" |
| 400 | **不重试**，展示原始错误（多半是模型 id 不存在） |
| 超时（>60s） | 提示重试，并提供"换模型重试" |
| JSON 解析失败 | 重试 1 次（加强 prompt 约束），仍失败则降级为正则提取 |

### 5.2 前端错误文案映射

| HTTP | 用户可见文案 |
|---|---|
| 401 | API Key 无效或已失效，请检查设置 |
| 403 | 无权访问该模型，账号可能未开通 |
| 404 | 模型不存在，请确认模型 id（当前：`{model}`） |
| 429 | 触发速率限制，请稍后重试或切换模型 |
| 5xx | 服务商暂时不可用，正在重试… |

### 6.5 JSON 容错解析

厂商不保证严格返回合法 JSON（尤其 Anthropic 与部分国产模型）。必须实现三级容错：

```ts
// src/engine/json.ts
export function parseLooseJSON<T>(raw: string): T | null {
  // 1. 直接尝试
  try { return JSON.parse(raw) as T; } catch {}

  // 2. 提取最外层 {...} 或 [...]
  const firstObj = raw.indexOf('{');
  const firstArr = raw.indexOf('[');
  let start = -1, end = -1;
  if (firstObj !== -1 && (firstArr === -1 || firstObj < firstArr)) {
    start = firstObj; end = raw.lastIndexOf('}');
  } else if (firstArr !== -1) {
    start = firstArr; end = raw.lastIndexOf(']');
  }
  if (start !== -1 && end > start) {
    const slice = raw.slice(start, end + 1);
    try { return JSON.parse(slice) as T; } catch {}
    // 3. 修复常见问题：尾逗号、单引号、截断
    try {
      const fixed = slice
        .replace(/,\s*([}\]])/g, '$1')     // 尾逗号
        .replace(/(\r\n|\n|\r)/g, '')      // 换行
        .replace(/,\s*"([^"]*)"\s*:\s*"([^"]*)"\s*$/, ',"$1":"$2"');
      return JSON.parse(fixed) as T;
    } catch {}
  }
  return null;
}
```

**如果三级都失败**：调用方必须降级——展示原始文本 + 提供"手动整理为子节点"的入口，**绝不静默失败**。

## 8. 密钥安全

```ts
// src/lib/crypto.ts —— WebCrypto AES-GCM，密钥由用户口令 PBKDF2 派生
export async function deriveKey(passphrase: string, salt: Uint8Array): Promise<CryptoKey> {
  const base = await crypto.subtle.importKey('raw', new TextEncoder().encode(passphrase), 'PBKDF2', false, ['deriveKey']);
  return crypto.subtle.deriveKey(
    { name: 'PBKDF2', salt, iterations: 210_000, hash: 'SHA-256' },
    base, { name: 'AES-GCM', length: 256 }, false, ['encrypt', 'decrypt'],
  );
}
```

**规则**
1. 默认 **不持久化 Key**（仅存内存，刷新即失效）。用户勾选「记住此 Key」时才落盘。
2. 落盘时用 AES-GCM 加密，密钥由用户口令派生；**口令不保存**，用户每次启动需输入。
3. 提供「本机免密」选项（密钥存 localStorage）——明确提示仅适合个人设备。
4. **任何日志、错误信息、导出文件中都不得包含 Key**。实现时在 `ProviderError` 构造处主动脱敏。
5. 设置页固定展示隐私声明：「洋葱不会将你的 Key 或知识数据发送至洋葱的任何服务器，仅直连你选择的模型厂商。」

### 7.3 语义校验（防死循环，必须实现）

```ts
// src/engine/guidedValidator.ts
export function validateGuidedQuiz(quiz: unknown): GuidedQuiz | null {
  const q = quiz as GuidedQuiz;
  if (!q?.steps?.length) return null;

  // ① 索引越界 → 降级为 next_question
  q.steps.forEach((s, i) => {
    const b = s.branching;
    if (!b) return;
    if (b.type === 'specific_question') {
      if (!Number.isInteger(b.index) || b.index < 0 || b.index >= q.steps.length) {
        b.type = 'next_question';
      }
    }
    if (b.type === 'response_based' && b.responseValues) {
      Object.keys(b.responseValues).forEach(k => {
        const v = b.responseValues[k];
        if (!Number.isInteger(v) || v < 0 || v >= q.steps.length || v === i) {
          delete b.responseValues[k];
        }
      });
      if (!Object.keys(b.responseValues).length) b.type = 'next_question';
    }
  });

  // ② 环检测：沿全部分支走一遍，超出 steps.length * 2 步即判定有环
  //    检出后把该边降级为 next_question
  if (hasCycle(q)) {
    // 逐边修复：找到导致环的边并降级
    repairCycles(q);
  }

  // ③ 可达性：从 step 0 出发走不到所有 step → 补兜底 next_question 边
  ensureReachable(q);

  // ④ 最后一步必须能终止
  const last = q.steps[q.steps.length - 1];
  if (!last.branching || last.branching.type !== 'end') {
    last.branching = { type: 'end' };
  }

  return q;
}
```

**这是分支问卷最大的线上风险**。Rabbithole 用 `responseValues` 跳转到具体索引，若 AI 返回了自指或成环的索引，用户会永远点不完。

### 7.4 路径决策引擎

```ts
export function nextStepIndex(
  quiz: GuidedQuiz,
  currentIndex: number,
  response: string | number | boolean | string[] | null,
): number | 'END' {
  const step = quiz.steps[currentIndex];
  const fallback: number | 'END' =
    currentIndex === quiz.steps.length - 1 ? 'END' : currentIndex + 1;

  const b = step.branching;
  if (!b?.type) return fallback;

  switch (b.type) {
    case 'end':
      return 'END';

    case 'specific_question':
      return Number.isInteger(b.index) ? b.index : fallback;

    case 'response_based': {
      if (!b.responseValues) return fallback;

      if (step.type === 'single_choice' && typeof response === 'string') {
        const idx = step.choices?.indexOf(response) ?? -1;
        const t = b.responseValues[String(idx)];
        return Number.isInteger(t) ? t : (t === 'END' ? 'END' : fallback);
      }

      if (step.type === 'rating' && typeof response === 'number') {
        // NPS 0-10 分档；3/5/7 量表分三档
        const bucket = bucketFor(step.scale ?? 10, response);
        const t = b.responseValues[bucket];
        return Number.isInteger(t) ? t : (t === 'END' ? 'END' : fallback);
      }

      if (step.type === 'multiple_choice' && Array.isArray(response)) {
        // 多选：取第一个被选中且有映射的选项
        for (const choice of response) {
          const idx = step.choices?.indexOf(choice) ?? -1;
          const t = b.responseValues[String(idx)];
          if (Number.isInteger(t)) return t;
        }
      }
      return fallback;
    }

    default:
      return fallback;
  }
}

/** NPS 0-10 与简化量表的分档 */
function bucketFor(scale: number, v: number): string {
  if (scale === 10) return v <= 6 ? 'detractors' : v <= 8 ? 'passives' : 'promoters';
  if (scale === 7) return v <= 3 ? 'negative' : v === 4 ? 'neutral' : 'positive';
  if (scale === 5) return v <= 2 ? 'negative' : v === 3 ? 'neutral' : 'positive';
  return v <= 1 ? 'negative' : v === 2 ? 'neutral' : 'positive';
}
```

### 7.5 回答 → 掌握度映射

```ts
export function applyGuidedResponse(
  step: GuidedStep,
  response: string | number | boolean | string[] | null,
  node: OnionNode | undefined,
): Partial<OnionNode> {
  if (!node) return {};

  if (step.type === 'rating' && typeof response === 'number') {
    // 评分低 = 自评没掌握
    const delta = response <= 3 ? -15 : response >= 8 ? +6 : 0;
    return { score: clamp(node.score + delta, 0, 100), needsExpand: delta < 0 ? true : node.needsExpand };
  }

  if (step.type === 'open' && typeof response === 'string' && response.trim().length > 0) {
    // 主动输出 = 强化记忆
    return {
      score: clamp(node.score + 5, 0, 100),
      qa: [...(node.qa || []), { q: step.question, a: response, at: Date.now() }],
    };
  }

  // 单选/多选：选中的分支 = 用户关心的部分
  const picks = Array.isArray(response) ? response : [response];
  const delta = picks.filter(p => typeof p === 'string').length * 8;
  return { score: clamp(node.score + delta, 0, 100) };
}
```

**"不了解/想跳过"选项的特殊处理**：若某选项文本包含"不了解""跳过""暂时不想"等语义，生成对应节点 `needsExpand = true` 且 `score` 归零。判定方式：生成时由 AI 在选项上标注 `flags: ["gap"]`，不依赖字符串匹配。

### 7.6 未走路径 → 待补全

```ts
export function markUnvisitedBranches(
  session: GuidedSession,
  quiz: GuidedQuiz,
  nodes: Record<string, OnionNode>,
): OnionNode[] {
  const visited = new Set<number>();
  let idx = 0;
  // 重放路径，记录实际走过的步
  while (idx !== 'END' && idx < quiz.steps.length) {
    visited.add(idx);
    const step = quiz.steps[idx];
    const next = nextStepIndex(quiz, idx, step.response ?? null);
    idx = next;
  }

  // 未走到的步骤 → 其 createsNode 对应节点标记待补全
  const updated: OnionNode[] = [];
  quiz.steps.forEach((s, i) => {
    if (visited.has(i) || !s.nodeId) return;
    const n = nodes[s.nodeId];
    if (!n || n.needsExpand) return;
    updated.push({ ...n, needsExpand: true, score: Math.min(n.score, 25) });
  });
  return updated;
}
```

**这是我们相对 Rabbithole 的核心增量**：一次探索的"未走路径"= 一张精确的待学清单。
