> 供 Code Agent 施工 ｜ 全部令牌值可直接落地为 CSS Variables

## 1. 设计基调

**关键词：安静、精密、可信。**

这是一款长时间陪伴思考的工具，不是消费级 App。视觉上要像一张摊开的纸质思维导图 + 一台精密仪器。

| 原则 | 具体要求 |
|---|---|
| **内容为王** | 画布占据 ≥70% 视觉权重，界面框架退到背景里。所有边框极轻（0.5px），不用阴影堆叠 |
| **洋葱隐喻贯穿** | 同心圆、层、剥开——这是产品的视觉签名，必须在画布、图标、空状态里一致出现 |
| **色彩即语义** | 环带颜色恒定对应层语义（L1 靛蓝 / L2 青 / L3 琥珀 / L4 紫 / L5 品红），形成肌肉记忆 |
| **暗色为默认** | 长时间阅读场景，暗色优先；亮色主题同样完整支持 |
| **克制的动效** | 只在"剥开"这一个核心动作上使用有叙事感的动画，其余一律 150ms 内的状态切换 |

## 4. 洋葱画布视觉规则（核心）

### 4.1 几何参数

```ts
export const CANVAS_GEOMETRY = {
  centerRadius:      68,    // L0 核心节点半径(px)
  ringGap:           152,   // 相邻层半径差
  nodeRadius:        26,    // 普通节点半径
  nodeRadiusFocused: 32,
  arcThickness:      2,     // 环带描边粗细
  arcOpacity:        0.10,  // 环带填充透明度
  angularPadding:    0.10,  // 扇区间隙占该扇区比例
  labelOffset:       44,    // 标签距节点中心距离
  minLabelGap:       18,    // 标签最小间距，防重叠
};
```

### 4.2 环带渲染

每一层是一个**环形扇区色带**（不是完整圆环），每个子节点占据父节点角度区间内的一段。

```
渲染顺序（从下到上）：
1. 环带填充    fill = 层色, opacity = 0.10
2. 环带描边    stroke = 层色, opacity = 0.35, width = 2
3. 父子连线    stroke = 层色, opacity = 0.28, width = 1.5, 曲线（见 4.3）
4. 节点圆      fill = 面板底色, stroke = 层色, width = 2
5. 节点文字    14px, --text-primary
6. 状态徽标    节点右下角小圆点
```

### 4.3 连线曲线

父子连线用**贝塞尔曲线**，控制点让线条从父节点"切向"射出，视觉上像洋葱纹理：

```ts
function linkPath(x1: number, y1: number, x2: number, y2: number): string {
  const dx = x2 - x1, dy = y2 - y1;
  const dist = Math.hypot(dx, dy);
  // 控制点偏移量随距离缩放，保证不同跨度下线形一致
  const k = Math.min(dist * 0.45, 90);
  const c1x = x1 + (dx / dist) * k;
  const c1y = y1 + (dy / dist) * k;
  const c2x = x2 - (dx / dist) * k;
  const c2y = y2 - (dy / dist) * k;
  return `M ${x1} ${y1} C ${c1x} ${c1y}, ${c2x} ${c2y}, ${x2} ${y2}`;
}
```

### 4.4 节点卡片样式

```
默认状态：
  圆形，fill = var(--bg-elevated)，stroke = 层色(2px)
  文字居中，最多两行，超出省略
  下方 44px 处放标题标签（12px, 居中）

悬停：
  半径 +2，stroke 亮度提升，阴影 --shadow-sm
  显示"展开/钻入"快捷按钮（节点右侧浮出小圆钮）

选中：
  外加一圈 3px 同色 30% 透明度的光晕（不是 box-shadow）

展开中：
  节点外围有一段旋转的虚线圆环（stroke-dasharray + animation: spin 1.2s linear infinite）
  颜色 = --status-expanding

待补全（needsExpand）：
  节点右上角挂一个橙色圆点（8px，--status-needs），带 1.5s 呼吸动画

掌握状态（节点内部小圆点，右下角）：
  已掌握 = 实心 --status-mastered
  模糊   = 半透明 --status-fuzzy
  未懂   = 空心描边 --status-unknown
```

### 4.5 剥开动效（核心叙事）

```
时间线（总 620ms）：
  0ms     父节点轻微放大 1.0 → 1.08，环带开始显现
  120ms   子节点从父节点位置开始（scale 0.3, opacity 0）
  120-520ms  沿贝塞尔曲线向目标位置移动 + scale 0.3 → 1.0，opacity 0 → 1
             各子节点按索引 stagger 延迟 60ms（依次"长出来"）
  520ms   父节点回弹 1.08 → 1.0
  620ms   环带描边由暗到亮扫过一圈（stroke-dashoffset 动画）

流式渲染时：子节点内容逐字上屏，节点半径随字数从 0 增长到最终值（弹性）
```

### 4.6 空状态

画布无内容时，中心显示洋葱剖面线稿（SVG，2px 描边，--border-default），下方：

```
        ⭘  ← 洋葱线稿
   还没有剥开任何知识

   [ 输入一个知识点 ]  或  拖入文本 / 导入文件
   
   试试：Transformer 是什么？  ·  机会成本  ·  大模型的注意力机制
```

三个示例词可点击直接播种。

## 5. 详情面板（右侧 384px）

### 5.1 头部区

```
┌────────────────────────────────────────┐
│ Transformer                    ⋯  ⤢    │  ← 标题 16px/600，可长按换行
│ [已掌握 ▾]  L2·机理  ●关联 3节点      │  ← 状态下拉 + 层标签 + 关系数

```

- 标题右侧 `⋯` 菜单：重命名 / 重新生成 / 删除 / 复制链接 / 移动到其他树 / 标记存疑
- `⤢` 按钮：全屏展开详情（临时覆盖画布）
- 状态徽标可点击下拉切换三态

### 5.2 视角切换 Tab

7 个 Tab，横向可滚动（`overflow-x: auto`，隐藏滚动条）：

```
[速览][原理][实证][应用][争议][关系][追问]
```

- 选中态：底部 2px 品牌色下划线 + 文字 --text-primary
- 未选中：文字 --text-tertiary
- **尚未生成内容的视角**，Tab 上带一个小圆点（表示"可生成"），点击即触发生成
- 生成中：Tab 内显示小型 spinner

### 5.3 内容区

- 正文使用 `--font-serif` + 15px/1.75，提升长文可读性
- Markdown 渲染：`marked` + `DOMPurify`（必须消毒，防 XSS）
- 公式用 KaTeX，行内 `$...$`，块级 `$$...$$`
- 列表、表格、代码块均有专门样式
- 每个内容区底部固定一行：`[↻ 重新生成]  [＋ 固化此观点为新节点]  [⚑ 标记存疑]`


### 4.5.4 祖先路径高亮（**丝滑的核心，必须实现**）

```ts
export const EDGE_DEFAULT   = { stroke: '#374151', strokeWidth: 2, transition: 'stroke 0.2s ease' };
export const EDGE_HIGHLIGHT = { stroke: 'hsl(var(--brand))', strokeWidth: 2, transition: 'stroke 0.2s ease' };

export function getAncestorEdgeIds(nodeId, nodeMap, edges): Set<string> {
  const ids = new Set<string>();
  let cur = nodeId;
  const node = nodeMap.get(cur);
  // 追问节点的路径起点是它引用的原节点
  if (node?.type === 'followUpNode') {
    const e = edges.find(x => x.target === cur);
    if (e) cur = e.source;
  }
  let guard = 0;
  while (cur && guard++ < 200) {
    const e = edges.find(x => x.target === cur);
    if (!e) break;
    ids.add(e.id);
    cur = e.source;
  }
  return ids;
}
```

**铁律**：`transition` 不可省。高亮必须是**"亮起来"而非"跳变"**，这是"丝滑"与"生硬"的分界线。

### 4.5.5 追问气泡规格

| 项 | 值 |
|---|---|
| 宽度 | `minWidth: 450px` |
| 圆角 | `rounded-[35px]` |
| 底色 | `bg-[#1a1a1a]` + `border border-[#333]` |
| 内边距 | `p-[30px]` |
| 文本域 | `bg-[#2a2a2a]` `rounded-2xl` `min-h-[130px]` `resize-none` |
| 按钮组 | `grid grid-cols-2 gap-3`，Ask 为主按钮 `bg-accent` |

**三个必须实现的细节**：
1. **挂载即聚焦** —— `useEffect(() => ref.current?.focus(), [])`，打开就能打字
2. **高度自适应** —— `el.style.height='auto'; el.style.height=el.scrollHeight+'px'`，随内容长高，永不出现内部滚动条
3. **Enter 提交 / Esc 取消** —— 键盘全程可用

### 4.5.6 转场时长基准（Rabbithole 实测值）

| 场景 | 时长 | 缓动 |
|---|---|---|
| 首页 → 探索页 | **700ms** | `ease-out` |
| 卡片 hover 浮现 | 300ms | `ease-in-out` |
| 边高亮 | 200ms | `ease` |
| 弹窗开合 | 200ms | `ease` |
| 按钮主色 hover | 500ms | `ease-in-out` |

**规则**：状态切换一律有过渡。超过 700ms 的动画在工具类应用里是灾难。

### 4.5.7 与原同心环视图的关系

同心环视图（§4.1–4.4）**降级为 P2 可选视图**。六层语义改由**节点层色 + 层徽标**表达：

| 层 | 徽标 | 卡片描边/圆点色 |
|---|---|---|
| L0 | 核心 | `--layer-0` 中性墨 |
| L1 | L1 构成 | `--layer-1` 靛蓝 |
| L2 | L2 机理 | `--layer-2` 青 |
| L3 | L3 边界 | `--layer-3` 琥珀 |
| L4 | L4 关联 | `--layer-4` 紫 |
| L5 | L5 延伸 | `--layer-5` 品红 |

层色**全局恒定** —— 任何树里的 L2 都是青色，用户靠颜色就能判断层级。
