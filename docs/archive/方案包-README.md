## 原型包含什么

`prototype/index.html` 是**真能跑的**，不是静态图：

- **卡片流画布（v1.2）** —— 对标 Rabbithole：左→右树状布局、**悬停高亮祖先路径**、卡片 hover 浮现追问、滚轮平移、右下 Minimap
- **六层语义展开** —— 点击节点按层语义生成子节点，带 620ms 剥开动画
- **七视角切换** —— 速览 / 原理 / 实证 / 应用 / 争议 / 关系 / 追问
- **出题判分** —— 选择题即时判分，自动更新掌握度
- **模型设置面板** —— 10 家厂商配置表单、Key 输入、连通性测试
- **命令面板** —— `⌘K` 唤起，支持模糊匹配
- **完整交互** —— 单击选中 / 双击钻入 / 滚轮缩放 / 拖拽平移 / 快捷键 / 主题切换
- **追问气泡** —— 挂载即聚焦、输入框高度自适应、Enter 提交 / Esc 取消
- **引导串探索面板** —— 分支问题串（单选/多选/NPS评分/开放）、回答决定路径、未走分支自动标记待补全

> 键盘：`E` 展开 · `F` 钻入 · `Q` 出题 · `M` 标记掌握度 · `1–7` 切视角 · `⌘K` 命令面板

## 核心设计：四句话

1. **双轴结构** —— 六层语义骨架（层）× 七个内容视角（视角），锁死 AI 展开的随机性，知识树不会长歪
   > v1.2：六层不再是同心环布局，改为**节点层色 + 层徽标**，卡片流负责自由探索
2. **引导串开路** ★ —— AI 生成分支问题串，你的回答决定下一步；每个回答都落成一个洋葱节点
3. **七步闭环** —— 播种 → 剥层 → 钻取 → 检验 → 复习 → 重组 → 再播种，三条回灌链路让知识主动回到你面前
4. **本地优先** —— 你的 Key 只存本机，除模型请求外不向任何自有服务器发数据

> **未走的路径 = 待学清单。** 一次探索的"没走到的分支"会被自动标记为待补全 —— 这是相对 Rabbithole 的核心增量。

## 关键决策速览

| 决策点 | 选择 | 理由 |
|---|---|---|
| 命名 | **洋葱 / Onion** | 洋葱横切面 = 天然同心圆结构，与层色语义完全同构 |
| 画布交互 | **卡片流 + 路径高亮** ★v1.2 | 直接采用 Rabbithole 已验证方案：悬停高亮祖先路径、卡片 hover 浮现追问、滚轮平移 |
| 形态 | 浏览器本地 Web App（PWA） | 无需后端，Key 不出本机，即开即用 |
| 模型接入 | 自研 Provider 抽象 | 8 家兼容 OpenAI 协议，1 家独立适配，总代码量最小 |
| 画布 | **React Flow + ELK** ★v1.2 | Rabbithole 同款，已验证的无限画布交互 |
| 布局算法 | **elkjs layered** ★v1.2 | 自动排位，新节点生长位置永远合理；不手写坐标 |
| 存储 | Dexie / IndexedDB | 前端最成熟的结构化本地库 |
| 画布 | 原生 SVG | 洋葱结构固定，SVG 便于动画与命中测试 |
