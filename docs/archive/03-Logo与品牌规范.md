# Logo 与品牌规范

> 供 Code Agent 施工 ｜ 所有 SVG 源文件位于 `brand/` 目录，可直接复制使用

---

## 1. 构形说明

Logo 采用 **「洋葱横切面 + 一层被剥开向外翻起」** 的复合构形：

```
        ╭─────╮      ← 剥开的那一层（向右上翻起并外移）
      ╭─┤     ├─╮
     │  ╰─────╯  │     ← 最外层：留有缺口，断口正对剥片
     │   ╭─────╮  │
     │  ╱       ╲  │    ← 中层：完整圆环
     │ │  ╭───╮  │ │
     │ │ │ ● │  │ │    ← 核心：实心圆点 = 知识的内核
     │ │  ╰───╯  │ │
     │  ╲       ╱  │
     │   ╰─────╯   │
      ╰───────────╯
```

**三层语义**

| 元素 | 视觉 | 语义对应 |
|---|---|---|
| 中心实心圆点 | 浅奶油色 `#FFDCA8` | 知识内核 / 本质（L0） |
| 向内递减的三层圆环 | 由外向内渐亮：`#C2691F` → `#E08B3C` → `#F7B267` | 洋葱的层，由外向内剥开 |
| 右上角剥片 | 独立月牙，向右上外移并旋转 -10° | 「剥开」这个动作本身——产品最核心的交互 |
| 最外环的缺口 | 44° 断口，与剥片同向 | 缺口 = 被剥离的位置，与剥片形成因果 |

**为什么这样设计**
1. **同心圆 = 洋葱的横切面**，是全宇宙最容易被识别的「一层层」符号，且与产品的六层同心环画布**完全同构**——图标即界面缩略。
2. **剥片外移 + 旋转**，把静态图形变成动态叙事：一眼看出「正在剥开」，而不只是「一圈圈的圆」。
3. **缺口与剥片严格对位**，让图形在逻辑上自洽——那一层是被从缺口处揭起来的。
4. **不画完整洋葱**（不加叶子、不写实），保持工具属性而非农产品属性。

### 使用规则

| 场景 | 用哪个 |
|---|---|
| 深色界面顶栏 | `logo-mark.svg` |
| 亮色界面顶栏 | `logo-on-light.svg` |
| 应用图标 / 桌面图标 / 安装横幅 | `logo-app-icon.svg` |

- 彩色版：最小 24px（低于此尺寸内环渐变会丢失层次）

- favicon 专用版：16–48px

## 4. 栅格与安全区

```
viewBox: 0 0 64 64
主图形外接圆：直径约 62（从 r=31.4 的剥片边缘算起）
安全区：图形外围至少留 4px（1/16 viewBox）
```

**比例关系（改图时必须保持）**
- 圆环半径比：4.4 : 9.8 : 17.2 : 24.4 ≈ 1 : 2.2 : 3.9 : 5.5
- 剥片半径：内 27.4 / 外 31.4
- 剥片旋转角：-10°
- 剥片角度跨度：-58° → -10°
- 缺口中心角：-30°，宽度 44°

**禁例**
- ❌ 不得改变各环半径比例
- ❌ 不得让剥片回到环内或与环体重叠
- ❌ 不得给 Logo 加渐变、阴影、描边
- ❌ 不得旋转整个图标
- ❌ 不得改变环的线宽（2.6 / 2.8 / 3.4 三档对应不同尺寸）
- ❌ 不得用完整版当 favicon

## 6. 品牌语调

| 原则 | 说明 |
|---|---|
| 不用营销腔 | 不写「赋能」「一站式」「智能革命」。产品文案说人话 |
| 承认不确定 | AI 生成内容标注可信度，允许标记「存疑」，不假装权威 |
| 不制造焦虑 | 不说「再不学就晚了」。复习队列用平静语气：「今天有 12 个待回顾」 |
| 尊重用户时间 | 每次调用前告知预估 token，不偷偷消耗 |

## 8. 资产生成说明

所有 SVG 由 `brand/` 下的源文件直接提供，**Code Agent 无需重新生成**，直接复制到项目 `public/brand/` 即可。

若需程序化生成（例如批量产出多尺寸 PNG），使用以下几何参数即可复现：

```
cx = cy = 32
core_r      = 4.4    fill  #FFDCA8
ring1_r     = 9.8    stroke #F7B267  sw 2.6
ring2_r     = 17.2   stroke #E08B3C  sw 2.6
ring3_r     = 24.4   stroke #C2691F  sw 2.8  (带 44° 缺口，中心 -30°)
peel_r_in   = 27.4   fill  #F2A65A
peel_r_out  = 31.4   角度 -58° → -10°，整体旋转 -10°
```
