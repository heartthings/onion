# 产品行为（现行）

洋葱是一个**本地优先**的知识地图：一个知识点进来，散开成一张图。模型请求从浏览器直连厂商，不经过洋葱服务器。数据在浏览器 IndexedDB（库名 `onion`）。

## 核心交互

1. **首页输入主题**  
   先做多义项判别（`classifySenses`）。若多个真实所指且置信度不够分，弹出选择器；否则直接建图。

2. **所指（Sense）**  
   - 一张图锁定一个 `sense`（`kind` + `gloss`）。  
   - 只保留真实对象（电影、人物、物种、经济学概念等），过滤「日常说法 / 口语 / 术语 / 概念」这类形态义项。  
   - 根卡片可「换成…」另开一张图，并带走其余 alternatives。

3. **散开**  
   子节点是「相关信息」，按 `value`（0–100）排序，不是「定义 / 要素 / 例子」栏目。设置里的 `childCount` 决定先展示几条，其余 `hidden`，用「下一批」放出。

4. **卡片 vs 侧栏**  
   - 卡片：标题、摘要、掌握度侧轨（懂了 / 模糊 / 不会）、功能按钮（散开、再找一批、重来、我写、对比、删除、下一批）。  
   - 侧栏：深度解读、笔记、答题。做过解读的节点卡片上标「已解读」。

5. **划线**  
   在深度解读里选中文字 → 出现「划线」浮钮（portal 到 `document.body`，避免被侧栏裁切）→ 写入 highlights，并进入复习。左侧列表悬停可删。

6. **收藏**  
   星标收藏。左侧列表悬停可取消。取消收藏时：若未标模糊/不会，对应复习卡一并去掉。

7. **掌握度**  
   - 懂了：非收藏节点会去掉当日复习卡。  
   - 模糊：排到明天（约 +24h），不立刻进「今天要复习」。  
   - 不会：立刻到期，需要复习。

8. **我写**  
   用户自建节点会自动选中并触发深度解读（若当前没有别的解读在流式输出）。

9. **继续追问**  
   解读末尾的追问可在旁边长出新节点；深度解读后还支持多轮 follow-up chat（见 `KNode.chat`）。

10. **导出**  
    顶栏「导出」：整张地图 Markdown、划线与笔记、Anki 文本。导出菜单在工具栏滚动区外，避免被裁切。

## 明确不是现状的旧设计

`docs/archive/` 里写过、但**现网没有**的东西：

- 六层语义骨架 / 七视角面板  
- ELK 同心环或 Rabbithole 式「引导串」主路径  
- 服务端存地图或 Key  

现网画布是 React Flow + `d3-hierarchy` 左右树布局。
